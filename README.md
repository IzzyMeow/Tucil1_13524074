# Penyelesaian Permainan Queens Linkedin

Program dibuat menggunakan Python berbasis GUI (Tkinter) untuk menyelesaikan permainan Queens Linkedin. Program menggunakan algoritma bruteforce murni dan menampilkan live update.

## Requirement & Installation
- Python 3.13
- Tkinter

## Cara Menjalankan Program
1. Masuk ke folder `src`
2. Jalankan program dengan perintah: python main.py
3. Klik Load Board untuk memuat file papan .txt
4. Klik Solve untuk menjalankan pencarian solusi
5. Solusi akan ditampilkan secara visual dan dapat disimpan ke folder test
